## Scientific Notation Application

### Conversion Standards
- All numerical values converted to scientific notation
- Precision maintained at 3 significant figures
- Special values handled (inf, -inf, nan, zero)
- Format: `X.YZeN` where X.YZ is mantissa, N is exponent

### Examples
- `87.3` → `8.730e1`
- `0.0019` → `1.900e-3`
- `100` → `1.000e2`
- `0.73` → `7.300e-1`
